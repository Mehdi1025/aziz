# aziz — KeyNest

Dashboard admin pour la gestion de distributeurs de clés (casiers), réservations, réseau national, Control Tower et abonnements loueurs.

## Démarrage

```bash
npm install
npm run db:seed
npm run dev -- -p 3001
```

- Admin : http://localhost:3001/admin
- Accueil : http://localhost:3001

## Stack

Next.js 16 · TypeScript · Tailwind 4 · Prisma 7 · SQLite · Leaflet
